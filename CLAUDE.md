# Монтаж роликов — рабочая база

Этот репозиторий — мастерская видеомонтажа кодом (вертикальные ролики 1080×1920, стиль сторителлинг / After Effects).
Пользователь пишет по-русски. Отвечать по-русски.

## Стили (главное правило)
Когда пользователь называет стиль — сначала загрузить его навык и паспорт, потом работать:

| Стиль | Как его называет пользователь | Навык | Паспорт |
|---|---|---|---|
| Сторителлинг | «сторителлинг», «в нашем стиле», «как с волком», «как Мона Лиза» | `.claude/skills/storytelling/` | `montage/styles/storytelling/STYLE.md` |
| Jatho (эксперт) | «Jatho», «как у Девина», «экспертный рилс», «говорящая голова как у Jatho» | `.claude/skills/jatho/` | `montage/styles/jatho/STYLE.md` |

Новый стиль (пользователь прислал новый референс и дал ему имя):
1. Разобрать референс → `montage/references/<имя>.md`.
2. Паспорт с цифрами → `montage/styles/<имя>/STYLE.md` (структура как у storytelling).
3. Навык → `.claude/skills/<имя>/SKILL.md` с триггерами в description.
4. Добавить строку в таблицу выше, закоммитить в `main`.

## С чего начинать новую сессию
1. `bash montage/setup.sh` — ставит opencv, rembg, fonttools, собирает шрифты (Playfair Display, Montserrat с кириллицей)
   и тестовые ассеты в `work/` (gitignored). Работает в облачном контейнере за прокси.
2. Прочитать `montage/references/*.md` — разборы референсов пользователя.
3. Шаблон рендера — `montage/projects/mona_lisa/render.py` (+ `sfx.py` для звука). Новый проект = копия этой папки.

## Пайплайн
- Разбор референса: `ffprobe`; склейки `ffmpeg -vf "select='gt(scene,0.12)',showinfo"`;
  контакт-листы `fps=1,scale=240:-1,tile=7x6` и плотные `fps=6` на сложных местах — смотреть кадры глазами.
- Рендер: Python + numpy/cv2, слои RGBA через `cv2.warpAffine`, камера = матрица поверх слоёв,
  motion blur = 4 субкадра с затвором 180°, грейд + виньетка + зерно. 4 процесса, ~2 мин на 9 с.
- Сборка: `ffmpeg -framerate 30 -i frames/%04d.png -i sfx.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac`.
- Звук синтезируется (`sfx.py`): дрон, whoosh на переходах, удары на поп-ап, тики машинки.

## Каталог приёмов (реализованы в render.py)
2.5D-параллакс (вырезка rembg, слой растёт быстрее фона) · интро-влёт с out_expo · медленный наезд in_out_cubic ·
плашки-имена с blur-выездом · рваные стикеры с out_back · zoom-blur переход со вспышкой ·
слова по одному (blur + подъём + fade) · печать по буквам.

## Уроки (не повторять ошибки)
- Параллакс: точка привязки масштаба (anchor) должна совпадать с точкой позиции, иначе слой съезжает и
  из фона проглядывает «двойник». Оба слоя масштабировать вокруг лица.
- Задним слоем брать оригинал (размытый), а не inpaint — inpaint даёт грязные пятна.
- Стикеры не ставить на лицо.
- Тень текста — одна мягкая (Drop Shadow: смещение 6 %, мягкость 25 % кегля). Чёрная обводка поверх тени = грязный край, пользователю не нравится.
- PIL не читает woff2 и кириллица у fontsource в отдельном сабсете — склеивать latin+cyrillic (`tools/fonts.py`).

## Озвучка
- ElevenLabs (claude.ai-коннектор): `creative_list_voices` (languages=['ru']) → `creative_generate_speech` с `estimate_only`
  → показать цену и получить «да» → генерация → `creative_get_flow_run_status` → скачать `content_url`
  (storage.googleapis.com открыт). Голос по умолчанию для сторителлинга: «Ivan — Multilingual Storyteller» `1kb4Md8n0kMNktygYhDF`, eleven_v4.
- Часто 429 (rate limit): повтор через минуту безопасен, если генерация не стартовала (в ответе нет session_id).
- Тайминг слов: `python3 montage/tools/align.py vo.mp3 script.txt words.json` (в script.txt числа как `1901|тысяча_девятьсот_первом`).
- Микс: голос сверху, фон с дакингом (`projects/zelimkhan/sfx.py`), при сборке `-af loudnorm=I=-14:TP=-1.5:LRA=11`.

## Ограничения среды
- Изменение сетевых настроек окружения в уже запущенном контейнере не подхватилось (наблюдение) — проверять в новой сессии.
- Сеть: работают GitHub (raw + releases), PyPI, npm, storage.googleapis.com. Не работают Unsplash/Pexels/Wikimedia/HF/Google Fonts,
  домены выдачи Canva/Runway. Unsplash MCP требует подтверждения почты у пользователя.
- Голова/лицо не оживляются кодом — нужен видеофутаж пользователя или image-to-video (Runway/Luma, платно).
- After Effects нет; на выходе MP4.

## Проекты
- `montage/lib/storykit.py` — общие хелперы стиля (камера, слои, плашки, стикеры, слова, zoom blur, грейд). Новые проекты импортируют его.
- `montage/projects/mona_lisa/` — тест 9 с: кража «Моны Лизы» в стиле референса `wolf_storytelling.md`.
- `montage/projects/zelimkhan/` — 49.5 с, абрек Зелимхан, озвучка ElevenLabs + субтитры. Визуал процедурный
  (горы, решётка, дело, рельсы, розыск, карта Natural Earth) — архивы фото были закрыты сетью; при открытой сети
  заменить сцены на реальные фото (портрет Зелимхана ~1910, старый Грозный, горы, паровоз).
- `montage/ae/` — **Caption AE** (`CaptionAE.jsx`): панель After Effects (ScriptUI) с вкладками. Фразы — обычные текстовые слои
  без прекомпоза, transform-выражения добавляются поверх своих значений слоя (можно двигать руками). «Субтитры»: Whisper через `transcribe.py`
  или импорт SRT/JSON; показ — фраза по словам / по одному слову / фраза целиком / блок из 2 строк; появление
  pop/выезд/blur/рубленый/подъём/flicker/удар/глитч, уход распад/вылет/blur/мерцание, «Микс» из отмеченных стилей,
  умный подбор по паузам/вопросам/темпу, акценты по громкости голоса, толчок + тряска на акцентах; типографика (крупное слово другим шрифтом,
  мелкие служебные, «Микс» по фразам; per-word шрифт/размер через characterRange, AE 2024+), свечение (Deep Glow / Glow) и блик
  CC Light Sweep. «Тряска»: нарастание/удар/
  постоянная, ритм, пресеты силы, резкость, зеркальные края. «Акцент-эффекты»: удар/пружина/толчок (+ тряска) на любые слои.
  Пресеты: «Сторителлинг — сдержанно» (по умолчанию: Playfair 74, слово из blur вверх, ключевое слово Black капсом ×2 с влётом 160%),
  «Динамично (TikTok)», «Jatho — эксперт» (поп фразой капсом, акцент цветом, панч-зум видео на акцентах скачком 12 %);
  «Простые субтитры» (стиль «Без анимации» + уход «Без ухода (обрыв)»: текст просто стоит, только мягкая тень);
  отдельная вкладка «Простые субтитры»: 1–6 слов на экране (строго или с разрывами на паузах), длительность по речи или фиксированная;
  «Заголовок-хук» Jatho на вкладке «Акцент-эффекты» (белая строка + цветная со свечением). Урок: «всё включено» = колхоз — по умолчанию один приём движения и редкий акцент.
  Проверка без AE: `montage/ae/preview/` — заглушка DOM AE + проигрыватель выражений плагина → MP4 (см. README там).
  Архив для тестировщиков: `python3 montage/ae/build_zip.py out.zip` (инструкции RU/EN для Windows/Mac и установщики в `install/`).
  Смысловые акценты — бесплатно: пользователь присылает текст из панели, Claude возвращает с `*акцентами*`.
