# Монтаж роликов — рабочая база

Этот репозиторий — мастерская видеомонтажа кодом (вертикальные ролики 1080×1920, стиль сторителлинг / After Effects).
Пользователь пишет по-русски. Отвечать по-русски.

## Стили (главное правило)
Когда пользователь называет стиль — сначала загрузить его навык и паспорт, потом работать:

| Стиль | Как его называет пользователь | Навык | Паспорт |
|---|---|---|---|
| Сторителлинг | «сторителлинг», «в нашем стиле», «как с волком», «как Мона Лиза» | `.claude/skills/storytelling/` | `montage/styles/storytelling/STYLE.md` |

Новый стиль (пользователь прислал новый референс и дал ему имя):
1. Разобрать референс → `montage/references/<имя>.md`.
2. Паспорт с цифрами → `montage/styles/<имя>/STYLE.md` (структура как у storytelling).
3. Навык → `.claude/skills/<имя>/SKILL.md` с триггерами в description.
4. Добавить строку в таблицу выше, закоммитить в `main`.

## С чего начинать новую сессию
1. `bash montage/setup.sh` — ставит opencv, rembg, fonttools, собирает шрифты (Playfair Display, Montserrat с кириллицей)
   и тестовые ассеты в `work/` (gitignored). Работает в облачном контейнере за прокси.
2. Прочитать `montage/references/*.md` — разборы референсов пользователя.
3. Шаблон рендера — `montage/projects/mona_lisa/render.py` (+ `sfx.py` для звука). Новый проект = копия этой папки.

## Пайплайн
- Разбор референса: `ffprobe`; склейки `ffmpeg -vf "select='gt(scene,0.12)',showinfo"`;
  контакт-листы `fps=1,scale=240:-1,tile=7x6` и плотные `fps=6` на сложных местах — смотреть кадры глазами.
- Рендер: Python + numpy/cv2, слои RGBA через `cv2.warpAffine`, камера = матрица поверх слоёв,
  motion blur = 4 субкадра с затвором 180°, грейд + виньетка + зерно. 4 процесса, ~2 мин на 9 с.
- Сборка: `ffmpeg -framerate 30 -i frames/%04d.png -i sfx.wav -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac`.
- Звук синтезируется (`sfx.py`): дрон, whoosh на переходах, удары на поп-ап, тики машинки.

## Каталог приёмов (реализованы в render.py)
2.5D-параллакс (вырезка rembg, слой растёт быстрее фона) · интро-влёт с out_expo · медленный наезд in_out_cubic ·
плашки-имена с blur-выездом · рваные стикеры с out_back · zoom-blur переход со вспышкой ·
слова по одному (blur + подъём + fade) · печать по буквам.

## Уроки (не повторять ошибки)
- Параллакс: точка привязки масштаба (anchor) должна совпадать с точкой позиции, иначе слой съезжает и
  из фона проглядывает «двойник». Оба слоя масштабировать вокруг лица.
- Задним слоем брать оригинал (размытый), а не inpaint — inpaint даёт грязные пятна.
- Стикеры не ставить на лицо.
- PIL не читает woff2 и кириллица у fontsource в отдельном сабсете — склеивать latin+cyrillic (`tools/fonts.py`).

## Ограничения среды
- Сеть: работают GitHub (raw + releases), PyPI, npm. Не работают Unsplash/Pexels/Wikimedia/HF/Google Fonts,
  домены выдачи Canva/Runway. Unsplash MCP требует подтверждения почты у пользователя.
- Голова/лицо не оживляются кодом — нужен видеофутаж пользователя или image-to-video (Runway/Luma, платно).
- After Effects нет; на выходе MP4.
