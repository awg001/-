# Референс: «Wolf of Wall Street» storytelling (реклама EarnEdits)

41.5 с, 720×1280, 30 fps. Стиль After Effects «сторителлинг».

## Структура
| Время | Сцена | Приёмы |
|---|---|---|
| 0–3 | «FAKE COCAINE» над больницей, медбрат везёт каталку | заголовок 3D-шрифт красный/белый, проезд камеры |
| 3–7 | Белфорт с купюрой, агенты ФБР на переднем плане | 2.5D-параллакс: передний план въезжает с краёв быстрее фона, медленный наезд |
| 6–8 | Постер «THE WOLF OF WALL STREET» | переход zoom blur, заголовок выезжает сверху |
| 8–11 | Белфорт и Джона на диване | плашки-имена (красная / синяя) выезжают с blur |
| 11–15 | Джона нюхает порошок | стикер «Vitamin-B» с рваной бумагой, поп с отскоком |
| 15–19 | Джона в больнице | раскрывается анатомия сердца + выноска «Severe Bronchitis» |
| 19–21 | Синий фон с сеткой | serif-текст по словам: «But it gets CRAZIER», ключевое слово крупно |
| 21–23 | Постер в тёмной галерее, силуэт | наезд, поворот камеры |
| 23–26 | 3D-карта Малайзии на светлом фоне | текст по словам «Money Stolen From Malaysia's State Fund» |
| 26–29 | Газета Washington Post на красном фоне | газета падает с тенью |
| 29–32 | Мужчина смотрит фильм по ТВ | композит в интерьер |
| 32–35 | Красный фон, слова «or … ultimate» italic serif | |
| 35–41 | «THE EDITORS MAKING WORK LIKE THIS» + мокап телефона | буквы падают, прокрутка сайта |

## Ключевое
- Жёстких склеек нет — всё через zoom blur / влёты.
- Камера всегда в движении: медленный наезд с ease-out, motion blur.
- Многие сцены — AI-стиллы, оживлённые image-to-video (движение голов) + параллакс.
