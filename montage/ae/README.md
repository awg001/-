# Caption AE — панель монтажа для After Effects

Одна панель, три вкладки:
- **Субтитры** — распознаёт речь, раскладывает текст на фразы, собирает анимированные текстовые слои;
- **Тряска** — дрожание кадра или слоёв для монтажа;
- **Акцент-эффекты** — резкий зум с посадкой, пружина, толчок (+ тряска) на любые слои.

Это скрипт-панель (ScriptUI): ставится копированием файла, встаёт в интерфейс AE как обычная панель плагина.

## Установка (один раз)
Пошаговые инструкции для тестировщиков — в `install/`: Windows и Mac, на русском и английском
(`Установка — Windows (RU).txt`, `Установка — Mac (RU).txt`, `Install — Windows (EN).txt`, `Install — Mac (EN).txt`).
Распознавание ставится одним кликом: `install_windows.bat` / `install_mac.command`.
Работает на Windows и macOS, включая Apple Silicon (M1–M4).

Коротко: `CaptionAE.jsx` + `transcribe.py` в `Scripts/ScriptUI Panels` → в AE включить
**Allow Scripts to Write Files and Access Network** → для распознавания Python 3.9+ и `faster-whisper`.

Архив для отправки: `python3 montage/ae/build_zip.py CaptionAE.zip`.

## Работа
1. Выделить слой с голосом → «Распознать речь слоя» (`small` быстрее, `medium` точнее для русского).
   Или «Импорт SRT / JSON»: SRT из Premiere (Text > Transcript / Captions > Export to SRT),
   JSON со словами из `montage/tools/align.py`.
2. В поле текста: одна строка = одна фраза на экране. Можно править слова, Enter делит фразу,
   `*слово*` — акцент (крупнее, акцентным цветом; в «Миксе» вся фраза входит ударом).
3. **Показ**: фраза со словами по мере речи · по одному слову (слово сменяет слово) · фраза целиком сразу ·
   блок из 2 строк. При смене показа текст перебивается автоматически.
4. Стиль → «Создать субтитры». Повторное нажатие пересобирает: старые слои Caption AE удаляются.

## Появление
| Стиль | Как входит |
|---|---|
| Микс | чередует спокойные стили без повторов; фразы с акцентом или «!» — по очереди «Удар» и «Глитч» |
| Pop | слова выпрыгивают с перелётом в свой момент речи (0,28 с, out-back) |
| Выезд снизу | слова выезжают на 70 px снизу (0,35 с, out-expo) |
| Из размытия | проявляются из blur 30 и 115% (0,40 с, out-cubic) |
| Рубленый | слово появляется резко, ровно когда сказано |
| Подъём строки | строка поднимается лесенкой (0,30 с, out-expo) |
| Мерцание (flicker) | слово мигает, всё реже гаснет и зажигается (0,35 с) |
| Удар | фраза влетает с 260% с размытием (0,22 с, out-expo) |
| Глитч | мерцание + рывки вбок до 90 px, затухают к концу (0,30 с) |

## Уход
| Стиль | Как уходит |
|---|---|
| Микс | акцентные фразы — распад, остальные по очереди без повторов |
| Быстрое затухание | 3 кадра |
| Распад на буквы | буквы разлетаются в стороны, падают, крутятся до 240°, размываются и гаснут, каждая со своей задержкой |
| Вылет вверх | слова слева направо улетают вверх с ускорением и blur |
| Уход в размытие | слова раздуваются до 118% и тают в blur |
| Мерцание | слова мигают и гаснут |

Уход занимает 0,3–0,4 с, но если сразу за фразой идёт следующая, он сжимается до 0,15 с, чтобы не съесть последнее слово.
Плюс караоке-подсветка текущего слова и motion blur (галочка, по умолчанию включён).

## Что разрешено «Миксу»
Галочками выбираются стили, из которых «Микс» собирает ролик: снятый стиль не появится нигде.
Если выключены «Удар» и «Глитч», акцентные фразы берут обычные стили; если выключен «Распад» — уходят обычным уходом.

**Умный подбор** (галочка) читает речь, а не смысл слов:
- акцент или «!» → «Удар» / «Глитч», уход — «Распад»;
- вопрос «?» → «Мерцание» или «Размытие»;
- фраза после паузы ≥ 0,8 с (новая мысль) → «Подъём», «Выезд» или «Размытие»;
- быстрая речь (< 0,22 с на слово) → «Рубленый» или «Pop»;
- середина предложения → уход быстрым затуханием (речь течёт дальше), конец предложения с паузой → заметный уход;
- в остальных случаях стили чередуются без повторов.

**Акценты по голосу**: `transcribe.py` меряет громкость каждого слова. В каждой фразе самое громкое слово,
которое громче обычного уровня голоса на N дБ (по умолчанию 5), становится `*акцентом*`; в тексте видно, лишнее можно стереть.
У SRT громкости нет — там акценты только вручную.

## Правка после сборки
- Каждая фраза — **обычный текстовый слой прямо в композиции**, без прекомпоза. Любую фразу можно двигать мышью,
  масштабировать, поворачивать, подрезать и сдвигать по времени отдельно — анимация и общие настройки сохраняются.
- Слой `CAPTION_CTRL` (эффекты): `Size %`, `Y offset`, цвета `Text` / `Highlight` / `Accent`, `Karaoke` вкл/выкл — меняют все фразы сразу.
- Текст фразы можно править прямо в слое (Source Text): анимация на expression-селекторах и сохранится.
- Стиль отдельной фразы: в слое Text > Animators > `Reveal …` поменять значения (Scale/Position/Blur).
- Тайминг: двигать/подрезать слой; слова отсчитываются от in-point слоя.

**Толчок + тряска на акцентах** (галочка): в момент акцентного слова вся фраза коротко толкается (до 125%) и вздрагивает.

## Типографика и свет (вкладка «Субтитры», блок 4)
**Типографика** — фраза собирается как композиция: одно слово крупное и другим шрифтом на своей строке,
короткие служебные слова (до 3 букв) мельче, остальные обычные.
- **Одинаковая** — все фразы обычным шрифтом.
- **Разная во всех фразах.**
- **Микс** — композиция на акцентных фразах и на каждой 3-й, остальные обычные (как по одному слову, так и фразой).

Крупное слово — акцент `*…*`, а если его нет, самое длинное слово (от 4 букв).
Настраивается: шрифт крупного слова (по умолчанию PlayfairDisplay-Black), размер крупного (160%) и мелких (65%).
Разные шрифт и размер внутри одной фразы — **After Effects 2024 и новее**; в старых версиях только раскладка по строкам.

**Свечение** — нет / на акцентных / на всех. Если установлен плагин Deep Glow, берётся он; иначе встроенный Glow
(порог 55, радиус ≈ 0,35 размера шрифта, интенсивность 1,3).
**Блик** — CC Light Sweep: световая полоса проходит по фразе слева направо за 0,6 с в момент акцентного слова.
На вкладке «Акцент-эффекты» есть кнопки «Свечение» и «Блик» для любых выделенных слоёв.

## Смысловые акценты (бесплатно, через Claude)
Скопировать текст из окна панели → прислать в чат → получить его с `*акцентами*` по смыслу (и, если надо, с другой разбивкой)
→ вставить обратно → «Создать субтитры». Время слов не теряется: оно привязано к порядку слов.

## Вкладка «Тряска»
Ставит дрожание с текущего кадра (плейхеда) на заданную длительность.

| Параметр | Что делает |
|---|---|
| Тип | **Нарастание** — от нуля до максимума, с ускорением (напряжение перед склейкой); **Удар** — сразу сильно и затухает; **Постоянная** |
| На | **весь кадр** — корректирующий слой `SHAKE` (края зеркалятся, чёрных полей нет); **выделенные слои** — эффект на сами слои |
| Ритм / Частота | Плавно 2 Гц · Средне 6 · Резко 14 · Очень резко 24, или своё число |
| Сила, Поворот, Зум | смещение в px, покачивание в градусах, «дыхание» масштаба в % |
| Резкость 1–4 | 1 — гладкие колебания, 4 — рваная мелкая дрожь поверх |
| Размытие в движении | смаз от тряски (затвор 180°) |
| Субтитры не трясти | слой `SHAKE` ставится под субтитрами |

После добавления всё правится на слое: эффекты `Shake amount / freq / px / rotation / zoom / sharpness / curve`.
Ключи `Shake amount` (0–100) — форма тряски: их можно двигать и добавлять свои; `curve` — 1 ровно, 2–3 круче нарастание/затухание.
Несколько трясок на одном слое не мешают друг другу (`Shake`, `Shake2`, …).

Пресет **Сила** (Мягкая / Средняя / Сильная) заполняет сдвиг, поворот и зум: 8 px·0,5°·1% / 25 px·1,5°·3% / 60 px·3,5°·7%.

## Вкладка «Акцент-эффекты»
Для выделенных слоёв — текст, видео, фото, фразы субтитров.

| Эффект | Как выглядит |
|---|---|
| Удар | слой резко прыгает до ~220% и садится на место с лёгким «проседанием» (0,25 с) |
| Пружина | появляется маленьким (~55%) и пружинит на место (0,6 с) |
| Толчок | короткий толчок до ~120% и обратно (0,22 с) — акцент посреди фразы |

Сила: мягко ×0,5 / средне ×1 / сильно ×1,6. «Длительность ×» растягивает или сжимает.
«+ резкая тряска» добавляет короткую дрожь в тот же момент. «С начала каждого слоя» — выделить все фразы субтитров и ударить каждую при появлении.
Потом сила меняется эффектом `Hit scale` на слое.

## Premiere Pro
Анимированные текстовые слои скриптом Premiere не собирает. Путь: встроенное распознавание Premiere
(Speech to Text) → Export SRT → импорт в Caption AE, или Dynamic Link композиции AE в Premiere.
