# AutoSubs — анимированные субтитры в After Effects

Панель для AE: распознаёт речь, раскладывает текст на фразы и собирает анимированные текстовые слои.

## Установка (один раз)
1. Положить `AutoSubs.jsx` и `transcribe.py` в одну папку:
   - как панель: `…/Adobe After Effects <версия>/Scripts/ScriptUI Panels/` → AE: Window > AutoSubs.jsx;
   - или любую папку → AE: File > Scripts > Run Script File…
2. AE: Preferences > Scripting & Expressions > включить **Allow Scripts to Write Files and Access Network**.
3. Для распознавания: Python 3.9+ и `pip install faster-whisper`. Модель (~0.5 ГБ для `small`)
   скачается при первом запуске. Без Python можно пользоваться импортом SRT.

## Работа
1. Выделить слой с голосом → «Распознать речь слоя» (`small` быстрее, `medium` точнее для русского).
   Или «Импорт SRT / JSON»: SRT из Premiere (Text > Transcript / Captions > Export to SRT),
   JSON со словами из `montage/tools/align.py`.
2. В поле текста: одна строка = одна фраза на экране. Можно править слова, Enter делит фразу,
   `*слово*` — акцент (крупнее, акцентным цветом; в «Миксе» вся фраза входит ударом).
3. Стиль → «Создать субтитры». Повторное нажатие пересобирает: старые слои AutoSubs удаляются.

## Стили
| Стиль | Как входит |
|---|---|
| Микс | чередует стили без повторов; фразы с акцентом или «!» — «Удар» |
| Pop | слова выпрыгивают с перелётом в свой момент речи |
| Выезд снизу | слова выезжают снизу, out-expo |
| Из размытия | слова проявляются из blur с лёгким уменьшением |
| Рубленый | слово появляется резко, ровно когда сказано |
| Подъём строки | вся строка поднимается лесенкой |
| Удар | вся фраза влетает из крупного плана с blur |

Плюс караоке-подсветка текущего слова и быстрый fade в конце фразы.

## Правка после сборки
- Слой `SUBS_CTRL` (эффекты): `Size %`, `Y offset`, цвета `Text` / `Highlight` / `Accent`, `Karaoke` вкл/выкл — меняют все фразы сразу.
- Текст фразы можно править прямо в слое (Source Text): анимация на expression-селекторах и сохранится.
- Стиль отдельной фразы: в слое Text > Animators > `Reveal …` поменять значения (Scale/Position/Blur).
- Тайминг: двигать/подрезать слой; слова отсчитываются от in-point слоя.

## Premiere Pro
Анимированные текстовые слои скриптом Premiere не собирает. Путь: встроенное распознавание Premiere
(Speech to Text) → Export SRT → импорт в AutoSubs, или Dynamic Link композиции AE в Premiere.
