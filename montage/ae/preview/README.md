# Виртуальный After Effects — предпросмотр Caption AE

Проверка плагина без After Effects:
1. `mock_ae.js` — заглушка DOM AE (композиция, слои, свойства, эффекты, ключи, `sourceRectAtTime`).
2. `render.js` запускает **настоящие** функции `CaptionAE.jsx` (`buildSubs`, `shakeFrame`, …) так же, как панель,
   затем кадр за кадром выполняет выражения, которые плагин записал в слои (появление, караоке, акценты, уход,
   удар, тряска, блик), и рисует текст через `@napi-rs/canvas`.

Motion blur как в AE: затвор 180°, 4 субкадра (≈ в 4 раза дольше; больше 2 процессов параллельно не хватает памяти).
Приближения: свой шум для `wiggle`, Glow / Light Sweep / Drop Shadow нарисованы вручную.

```bash
bash montage/setup.sh                       # шрифты в work/fonts
npm i --prefix /tmp/vae @napi-rs/canvas@0.1.65
export NODE_PATH=/tmp/vae/node_modules
node montage/ae/preview/render.js out 0 648  # кадры + layers.txt (что создал плагин) + panel_text.txt
ffmpeg -framerate 30 -i out/%04d.png -i montage/projects/zelimkhan/zelimkhan.mp4 -map 0:v -map 1:a -t 21.6 \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac preview.mp4
```
Сцены: `SCENE=story` (по умолчанию) — пресет «Сторителлинг — сдержанно» на весь отрывок; `SCENE=mix` — всё включено.
Сцена mix: 21,6 с голоса из ролика про Зелимхана; 0–15 с — фразы по мере речи, «Микс», умный подбор,
типографика «Микс», свечение и блик на акцентах; 15–21 с — по одному слову; нарастающая тряска кадра 17,4–19 с.

Что нашёл первый прогон (исправлено в плагине): крупное слово не влезало в кадр; одинокое «—» уходило на свою строку;
в режиме «по одному слову» типографика срабатывала без акцента; караоке-увеличение 108% съедало пробел между словами.

## Интерфейс без AE
`node montage/ae/preview/ui_preview.js out` — запускает настоящий UI-код `CaptionAE.jsx` на заглушке ScriptUI и пишет
`out/tab_N.html` по вкладке в тёмном стиле AE (снимки — Playwright). Так нашлась ошибка: значения по умолчанию
«Появление/Уход» брались как последний пункт списка и после добавления «Без анимации» перестали совпадать с пресетом.

## ExtendScript = ES3
`ui_preview.js` перед запуском панели удаляет из песочницы всё, чего нет в ExtendScript After Effects:
`Array.prototype.indexOf/map/filter/forEach/…`, `String.prototype.trim`, `JSON`, `Object.keys`, `bind`.
Код, который на это опирается, падает здесь так же, как в AE (так нашлась ошибка v0.12:
«Function STYLE_KEYS.indexOf is undefined» → пустая панель). Проверить старую версию: `JSX=путь/к/CaptionAE.jsx node ui_preview.js out`.

## Самопроверка всей панели
`node selftest.js` — запускает настоящий код панели в песочнице ES3 поверх мока AE (мок, как AE, делает недействительными
ссылки на свойства после addProperty/remove) и нажимает все кнопки во всех режимах: пресеты, стили, уходы, показ,
типографика и свет, галочки, перекраска, SRT, простые субтитры, тряска (тип × цель × ритм × сила), акценты, свечение, блик,
заголовки. Падает на любой ошибке или алерте и на тряске без ключей. Запускать перед каждой сборкой архива.
