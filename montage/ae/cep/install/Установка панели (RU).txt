CAPTION AE — ПАНЕЛЬ С ВКЛАДКАМИ (CEP)

Это та же Caption AE, но новой панелью: вкладки сверху (Субтитры · Простые · Эффекты · Инструменты · ⚙),
всё помещается без прокрутки по сто раз, есть вкладка «Инструменты» (точка привязки, выравнивание, нуль, bounce,
сглаживание ключей, разбить текст, счётчик, разложить проект по папкам). After Effects 2020 и новее.

УСТАНОВКА — выберите один способ
А) Windows: распакуйте архив целиком → двойной щелчок install_panel_windows.bat
   Mac: распакуйте → правый клик по install_panel_mac.command → Открыть → Открыть
Б) Через ZXP-установщик (aescripts ZXP Installer, Anastasiy's Extension Manager): перетащите CaptionAE.zxp.

Затем перезапустите After Effects: Window → Extensions → Caption AE.

РАСПОЗНАВАНИЕ РЕЧИ
Нужен Python 3.9–3.13 (python.org; на Windows отметьте «Add python.exe to PATH»).
В панели: ⚙ → «Проверить», и если не установлено — «Установить распознавание» (1–3 минуты, нужен интернет).
Или панель сама предложит установку при первом «Распознать речь слоя».

ЕСЛИ ПАНЕЛЬ ПУСТАЯ ИЛИ ЕЁ НЕТ В МЕНЮ
— Запустите установщик ещё раз и полностью перезапустите AE.
— Mac: Системные настройки → Конфиденциальность → разрешите запуск, если macOS заблокировала установщик.
Старая панель (CaptionAE.jsx в ScriptUI Panels) продолжает работать — можно держать обе.
