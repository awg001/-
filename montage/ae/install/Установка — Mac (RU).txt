CAPTION AE — УСТАНОВКА НА MAC (macOS)
=====================================
Панель для After Effects: анимированные субтитры, тряска кадра, акцент-эффекты.
Работает на любых Mac, включая MacBook на Apple M1–M4.

ЧТО НУЖНО
• After Effects 2020 или новее. Разные шрифт и размер слов в одной фразе — AE 2024 и новее.
• Для автоматического распознавания речи — Python 3.9 или новее (бесплатно).
  Без Python работают импорт SRT, тряска и акцент-эффекты.

ШАГ 1. СКОПИРОВАТЬ ПЛАГИН
1. Закройте After Effects.
2. Finder → Программы (Applications) → Adobe After Effects <версия> → Scripts → ScriptUI Panels
   (полный путь: /Applications/Adobe After Effects 2025/Scripts/ScriptUI Panels/)
3. Перетащите туда файлы CaptionAE.jsx, transcribe.py и папку CaptionAE_sounds (звуки).
   macOS попросит пароль администратора — введите пароль от Mac.
4. Запустите After Effects → меню Window (Окно) → внизу списка CaptionAE.jsx.

Без копирования: File → Scripts → Run Script File… → выбрать CaptionAE.jsx
(transcribe.py и CaptionAE_sounds должны лежать в той же папке).

ШАГ 2. РАЗРЕШИТЬ СКРИПТУ РАБОТАТЬ С ФАЙЛАМИ
After Effects → Settings (в старых версиях Preferences) → Scripting & Expressions →
включить «Allow Scripts to Write Files and Access Network».
(В русской версии: After Effects → Настройки → Сценарии и выражения →
«Разрешить сценариям записывать файлы и осуществлять доступ к сети».)

ШАГ 3. РАСПОЗНАВАНИЕ РЕЧИ (ОДИН РАЗ)
1. Скачайте Python для macOS: https://www.python.org/downloads/macos/ и установите (Продолжить → Установить).
2. Запустите install_mac.command из этого архива:
   кликните ПРАВОЙ кнопкой → «Открыть» → «Открыть»
   (обычный двойной клик macOS может заблокировать как файл из интернета).
   Откроется Терминал — дождитесь «Готово».
3. При первом распознавании скачается модель (~0,5 ГБ для small) — нужен интернет.
   Дальше всё работает без интернета, бесплатно. На M1–M4 распознавание быстрое.

КАК ПОЛЬЗОВАТЬСЯ
1. Откройте композицию, выделите слой с голосом (видео или аудио).
2. Вкладка «Субтитры» → «Распознать речь слоя» (идёт в фоне, проценты — в строке статуса; AE можно пользоваться).
   Или «Импорт SRT / JSON» — например, SRT из Premiere Pro.
3. Проверьте текст: одна строка = одна фраза; *слово* в звёздочках = акцент.
4. Выберите показ, стиль, типографику → «Создать субтитры».
5. Каждая фраза — обычный текстовый слой: его можно двигать, масштабировать, править.
   Общий размер, высота и цвета — эффекты на слое CAPTION_CTRL.
6. «Словарь замен…» — один раз впишите слова, которые распознавание пишет неправильно
   (как распознало = как надо, например: зелим хан = Зелимхан). Дальше исправляется само.
7. «Экспорт SRT» — файл субтитров для YouTube, TikTok, Premiere.
8. Звук: раздел «Звук» — whoosh на появление фраз и удар на акцентах.
   Свои звуки: папка с подпапками whoosh и hit (WAV/MP3).

ШРИФТЫ
По умолчанию Montserrat ExtraBold и Playfair Display Black (бесплатно: fonts.google.com;
установка — двойной клик по файлу шрифта → «Установить»).
Или впишите в поле шрифта PostScript-имя своего (например Helvetica-Bold).

ЕСЛИ ЧТО-ТО НЕ ТАК
• «install_mac.command не может быть открыт» → правый клик → «Открыть»,
  или Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
• «Распознавание не удалось» → откройте Терминал, наберите  which python3  и вставьте
  показанный путь в поле Python на панели (например /usr/local/bin/python3).
• Ошибка SSL / certificate при первом распознавании → в Finder: Программы → Python 3.x →
  дважды кликните «Install Certificates.command».
• Просит включить разрешение → см. шаг 2.
• «Распознавание не установлено…» → нажмите «Да»: панель сама поставит его в тот Python, которым пользуется (1–3 мин).
• Любая другая ошибка → пришлите скриншот (в окне ошибки указан номер строки).
