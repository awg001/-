CAPTION AE — УСТАНОВКА НА WINDOWS
==================================
Панель для After Effects: анимированные субтитры, тряска кадра, акцент-эффекты.

ЧТО НУЖНО
• After Effects 2020 или новее. Разные шрифт и размер слов в одной фразе — AE 2024 и новее.
• Для автоматического распознавания речи — Python 3.9 или новее (бесплатно).
  Без Python работают импорт SRT, тряска и акцент-эффекты.

ШАГ 1. СКОПИРОВАТЬ ПЛАГИН
1. Закройте After Effects.
2. Откройте папку:
   C:\Program Files\Adobe\Adobe After Effects <версия>\Support Files\Scripts\ScriptUI Panels\
   (например ...\Adobe After Effects 2025\Support Files\Scripts\ScriptUI Panels\)
3. Скопируйте туда файлы CaptionAE.jsx, transcribe.py и папку CaptionAE_sounds (звуки).
   Windows попросит права администратора — нажмите «Продолжить».
4. Запустите After Effects → меню Window (Окно) → внизу списка CaptionAE.jsx.
   Панель можно пристыковать к любому краю, как обычную панель.

Без копирования: File → Scripts → Run Script File… → выбрать CaptionAE.jsx
(transcribe.py и CaptionAE_sounds должны лежать в той же папке).

ШАГ 2. РАЗРЕШИТЬ СКРИПТУ РАБОТАТЬ С ФАЙЛАМИ
Edit → Preferences → Scripting & Expressions →
включить «Allow Scripts to Write Files and Access Network».
(В русской версии: Редактирование → Установки → Сценарии и выражения →
«Разрешить сценариям записывать файлы и осуществлять доступ к сети».)

ШАГ 3. РАСПОЗНАВАНИЕ РЕЧИ (ОДИН РАЗ)
1. Скачайте Python: https://www.python.org/downloads/windows/
2. При установке ОБЯЗАТЕЛЬНО отметьте галочку «Add python.exe to PATH», затем «Install Now».
3. Дважды кликните install_windows.bat (из этого архива) и дождитесь «Готово».
4. При первом распознавании скачается модель (~0,5 ГБ для small) — нужен интернет.
   Дальше всё работает без интернета, бесплатно.

КАК ПОЛЬЗОВАТЬСЯ
1. Откройте композицию, выделите слой с голосом (видео или аудио).
2. Вкладка «Субтитры» → «Распознать речь слоя» (идёт в фоне, проценты — в строке статуса; AE можно пользоваться).
   Или «Импорт SRT / JSON» — например, SRT из Premiere Pro.
3. Проверьте текст: одна строка = одна фраза; *слово* в звёздочках = акцент.
4. Выберите показ, стиль, типографику → «Создать субтитры».
5. Каждая фраза — обычный текстовый слой: его можно двигать, масштабировать, править.
   Общий размер, высота и цвета — эффекты на слое CAPTION_CTRL.
6. «Словарь замен…» — один раз впишите слова, которые распознавание пишет неправильно
   (как распознало = как надо, например: зелим хан = Зелимхан). Дальше исправляется само.
7. «Экспорт SRT» — файл субтитров для YouTube, TikTok, Premiere.
8. Звук: «Настройки ▸» → «Звук» — whoosh на появление фраз и удар на акцентах.
   Свои звуки: папка с подпапками whoosh и hit (WAV/MP3).

ШРИФТЫ
По умолчанию Montserrat ExtraBold и Playfair Display Black (бесплатно: fonts.google.com).
Установите их или впишите в поле шрифта PostScript-имя своего (например Arial-BoldMT).

ЕСЛИ ЧТО-ТО НЕ ТАК
• «Распознавание не удалось» / python не найден → переустановите Python с галочкой «Add python.exe to PATH»
  или впишите в поле Python на панели: py
• Просит включить разрешение → см. шаг 2.
• Панели нет в меню Window → проверьте, что файл лежит именно в «ScriptUI Panels», и перезапустите AE.
• Любая другая ошибка → пришлите скриншот (в окне ошибки указан номер строки).
