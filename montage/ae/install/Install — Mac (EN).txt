CAPTION AE — INSTALLING ON MAC (macOS)
======================================
An After Effects panel: animated captions, screen shake, accent effects.
Works on any Mac, including Apple Silicon (M1–M4) MacBooks.

REQUIREMENTS
• After Effects 2020 or newer. Mixed fonts and sizes inside one caption need AE 2024 or newer.
• For automatic speech recognition: Python 3.9 or newer (free).
  Without Python you can still import SRT and use Shake and Accent effects.

STEP 1. COPY THE PLUGIN
1. Quit After Effects.
2. Finder → Applications → Adobe After Effects <version> → Scripts → ScriptUI Panels
   (full path: /Applications/Adobe After Effects 2025/Scripts/ScriptUI Panels/)
3. Drag BOTH files there: CaptionAE.jsx and transcribe.py.
   macOS will ask for your administrator password.
4. Start After Effects → Window menu → CaptionAE.jsx at the bottom of the list.

Without copying: File → Scripts → Run Script File… → choose CaptionAE.jsx
(transcribe.py must be in the same folder).

STEP 2. ALLOW THE SCRIPT TO USE FILES
After Effects → Settings (Preferences in older versions) → Scripting & Expressions →
enable "Allow Scripts to Write Files and Access Network".

STEP 3. SPEECH RECOGNITION (ONCE)
1. Download Python for macOS: https://www.python.org/downloads/macos/ and install it.
2. Run install_mac.command from this archive:
   RIGHT-click it → "Open" → "Open"
   (a plain double-click may be blocked by macOS as a downloaded file).
   Terminal opens — wait for "Done".
3. The first recognition downloads the model (~0.5 GB for "small") — internet needed once.
   After that everything runs offline and free. Recognition is fast on M1–M4.

HOW TO USE
1. Open a composition and select the layer with the voice (video or audio).
2. "Субтитры" (Captions) tab → «Распознать речь слоя» (Transcribe layer). AE freezes while it works — that's normal.
   Or «Импорт SRT / JSON» (Import SRT / JSON), e.g. an SRT exported from Premiere Pro.
3. Check the text: one line = one caption; *word* in asterisks = accent.
4. Pick display mode, style, typography → «Создать субтитры» (Create captions).
5. Every caption is a regular text layer: move it, scale it, edit it.
   Global size, height and colors live as effects on the CAPTION_CTRL layer.
(The panel interface is in Russian; this guide gives the English meaning of each button.)

FONTS
Defaults are Montserrat ExtraBold and Playfair Display Black (free at fonts.google.com;
double-click a font file → "Install").
Or type the PostScript name of your own font (e.g. Helvetica-Bold).

TROUBLESHOOTING
• "install_mac.command can't be opened" → right-click → "Open",
  or System Settings → Privacy & Security → "Open Anyway".
• "Recognition failed" → open Terminal, type  which python3  and paste the path it prints
  into the Python field of the panel (e.g. /usr/local/bin/python3).
• SSL / certificate error on first recognition → Finder: Applications → Python 3.x →
  double-click "Install Certificates.command".
• Asked to enable a permission → see Step 2.
• Any other error → send a screenshot (the error box shows a line number).
