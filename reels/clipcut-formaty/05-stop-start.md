# 5. Stop-Start: разбор монтажа чужого Reels с названием приёмов

**Формат ClipCut:** 2 секунды исходника, новая мысль, 1 секунда с подписью приёма, ещё 3 секунды, фраза подлиннее, дальше свободный разбор. Каждый приём называется профессиональным словом в момент, когда он появляется.
**Под нас:** это формат ровно для монтажёра. Берём сильный Reels (монтаж, моушн, реклама) и называем приёмы по ходу. Чем точнее названия, тем яснее, что вы в этом разбираетесь.

Чем отличается от Reaction (ролик 1): там клип сначала целиком, а разбор про то, почему смотрит зритель. Здесь разбор с первой секунды, рваный ритм, и главное в названиях приёмов.

- Режим: экспертный.
- Зритель в начале думает: «красиво смонтировано, а почему, не знаю».
- Зритель в конце понимает: «у каждого эффекта есть название и задача».
- Длина: 45-60 с. Стиль: UI / SaaS (подписи приёмов как UI-чипы, таймкод, скраббер исходника).

## Подготовка

1. Выбрать Reels с 5-7 приёмами, которые видно глазом. Лучше автора, чей монтаж ваша аудитория знает.
2. Прислать MP4, прогнать razbor-montazha: склейки с таймкодами и монтажный лист.
3. По монтажному листу проставить настоящие приёмы и таймкоды в таблицу ниже. Не подписывать то, чего нет в кадре.

## Словарь приёмов (подставлять только то, что реально есть)

| Подпись на экране | Что это одной фразой |
|---|---|
| Текстовый хук | заголовок в первом кадре, тема ясна без звука |
| Склейка на действии | склейка внутри движения, её не видно |
| J-cut | звук следующего кадра начинается раньше картинки |
| L-cut | звук прошлого кадра тянется на новый |
| Match cut | форма или движение совпадает в двух кадрах |
| Speed ramp | скорость меняется внутри плана |
| Кинетический текст | слова появляются в ритме речи |
| Whoosh под переход | звук «проводит» глаз через склейку |
| Hit на акценте | удар в звуке на главном слове |
| Смена плана на повороте | крупность меняется в момент новой мысли |

## Монтаж

- **Макет:** исходник в карточке-«экране» сверху (скругление, мягкая тень, без тёмной подложки), под ним тонкий скраббер с таймкодом исходника. Я снизу или голосом за кадром.
- **Чипы:** UI-подписи у места приёма, SF Pro Display Semibold, светлые с размытием фона. Появление на пружине 4-6 кадров, чип остаётся до следующего стопа.
- **Стоп:** freeze плюс короткий щелчок, скраббер замирает. На поворотах вместо щелчка hit.
- **Текстовый хук:** SF Pro Display Bold, верхняя треть, над карточкой.
- **Субтитры:** Inter Medium (вид по файлу 1). Не перекрывать карточку с исходником.
- **Звук:** исходник на полной громкости, когда играет, и выключен на стопе. Так ритм слышно даже без картинки.
- **Автор:** ник автора исходника в карточке весь ролик.

## Чек-лист

- [ ] Все приёмы и таймкоды взяты из разбора, а не по памяти.
- [ ] Каждое название приёма объяснено одной простой фразой: жаргон без объяснения не понять.
- [ ] Ритм «играет, стоп» без длинных пауз.
- [ ] Самый сильный приём на повороте, а не в начале.
- [ ] Автор исходника указан, без призыва в конце.
